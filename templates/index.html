Como funciona a equivalência do CUB para parcelas

No mercado imobiliário em fase de obras (venda na planta), as parcelas não sofrem juros compostos bancários (PRICE/SAC). Em vez disso, a dívida é convertida para uma moeda teórica da construção civil: o CUB. Este documento orienta a implementação dessa regra de negócio no backend Node.js (TypeScript / JavaScript) com precisão matemática.

Princípio 01
CUB-Base é Imutável

O CUB do mês da assinatura é gravado no banco de dados e nunca muda até o término da obra.

Princípio 02
Dívida em Cotas CUB

O modelo no PostgreSQL/MongoDB deve persistir a quantidade de CUBs de cada parcela (4 casas decimais).

Princípio 03
Reajuste no Vencimento

No mês de faturamento da cobrança, multiplica-se a cota fixa pelo CUB homologado daquele mês.

01. O Exemplo Fundamental

Imóvel de R$ 550.000,00 ÷ CUB de Agosto/2023

CUB Ago/2023 = R$ 2.750,52
A Fórmula da Equivalência
Valor em Reais (R$) CUB-Base Contratual
=
R$ 550.000,00 R$ 2.750,52
=
199,9622 CUBs

O que este número significa na API Node.js?

No momento em que a proposta é fechada em Agosto de 2023, o cliente não comprou "R$ 550.000,00 em moeda corrente". Ele assumiu um compromisso indexado de entregar exatamente 199,9622 CUBs à incorporadora.

Na construção civil, os custos de concreto, ferro, mão de obra e insumos sobem ao longo dos anos. Se o empreendimento levar 36 meses para ser entregue, o saldo em cotas CUB preserva o poder de compra da obra contra a inflação setorial.

Evolução Temporal • Impacto no Saldo Devedor
Na Assinatura (08/2023): 199,9622 × R$ 2.750,52 = R$ 550.000,00
Hoje (CUB 10/2026 @ R$ 3.171,96): 199,9622 × R$ 3.171,96 = R$ 634.272,00
Variação Total Acumulada: + R$ 84.272,00 (+15,32%)
02. Arquitetura da Solução

O Algoritmo em 4 Passos no Node.js

Como estruturar os serviços, schemas (Prisma/TypeORM/Mongoose) e endpoints.

PASSO 01 Na Criação do Contrato

Congelamento do CUB-Base

Ao salvar o contrato via API Node.js, busca-se o índice do mês acordado (ex: 08/2023 -> 2750.52) e congela-se no registro.

// Objeto salvo no banco (ex: Prisma / Postgres):
const contrato = {
  valorNominalReais: 550000.00,
  cubBaseAnoMes: "2023-08",
  cubBaseValor: 2750.5200,
  totalCotasCUB: 199.9622
};
PASSO 02 Desdobramento de Parcelas

Decomposição em Cotas Fixas

Cada evento do cronograma (sinal, entrada, mensais, chaves) recebe sua fração de CUB: cota = valor / cubBase.

// Cotas fixadas das parcelas de R$ 550.000:
• Sinal (10%): 55.000 / 2750.52 = 19.9962 CUBs
• Entrada (20%): 110.000 / 2750.52 = 39.9924 CUBs
• 24x Mensais: 13.750 / 2750.52 = 4.9991 CUBs cada
• Chaves (10%): 55.000 / 2750.52 = 19.9962 CUBs
PASSO 03 Rotina Agendada

Cron de Ingestão Sinduscon

No início de cada mês, um job no Node.js (`node-cron` ou fila BullMQ) ingere o CUB recém-publicado e grava na tabela de série temporal.

// Tabela temporal `cub_historico`:
{ anoMes: "2023-08", valor: 2750.5200 }
{ anoMes: "2023-09", valor: 2756.1400 }
...
{ anoMes: "2026-10", valor: 3171.9600 }
PASSO 04 Faturamento da Parcela

Emissão do Boleto / PIX

No mês do vencimento, o gateway de pagamento calcula: valorFinal = cotaCUB * cubVigente.

// Cálculo executado no checkout/gerador de boleto:
valorBoleto = cotaParcela * cubMesVigente;
Ex: 4.9991 CUBs * R$ 3.171,96 (10/2026)
= R$ 15.856,94 (em vez de R$ 13.750,00)
03. Implementação Canônica

Módulo de Domínio em Node.js

Código limpo e modular pronto para produção (Express, Fastify, NestJS ou Lambdas).

Node.js 20+ / ESM & TS
src/services/cubService.ts (ou .js) Precisão Regulamentar 4 Decimais 
// ============================================================================
// Módulo Financeiro CUB - Regras de Domínio em Node.js
// ============================================================================

/**
 * Converte um valor monetário (R$) para cotas imutáveis de CUB.
 * @param {number} valorNominal - Valor em Reais (ex: 550000.00 ou parcela de 13750.00)
 * @param {number} cubBaseValor - CUB do mês de assinatura (ex: 2750.52)
 * @returns {number} Cotas fixadas com 4 casas decimais
 */
export function calcularCotaCUB(valorNominal: number, cubBaseValor: number): number {
  if (!cubBaseValor || cubBaseValor <= 0) {
    return 0;
  }
  const cota = valorNominal / cubBaseValor;
  // Math.round garante ausência de desvios IEEE-754 em frações monetárias
  return Math.round(cota * 10000) / 10000;
}

/**
 * Calcula o valor atualizado do boleto/cobrança no mês de vencimento.
 * @param {number} cotaCUB - Cotas da parcela armazenadas no banco (ex: 4.9991)
 * @param {number} cubVigente - CUB oficial publicado para o mês (ex: 3171.96)
 * @returns {number} Valor final em Reais para faturamento (2 decimais)
 */
export function atualizarParcela(cotaCUB: number, cubVigente: number): number {
  const valor = cotaCUB * cubVigente;
  return Math.round(valor * 100) / 100;
}

/**
 * Exemplo de Controller / Rota em Node.js (Express / Fastify)
 */
export async function faturarParcelaHandler(req: any, res: any) {
  const { parcelaId } = req.params;

  // 1. Busca a parcela no banco de dados
  const parcela = await db.parcelas.findUnique({ where: { id: parcelaId } });
  
  // 2. Obtém o CUB divulgado pelo Sinduscon para a competência do faturamento
  const cubAtual = await db.cubHistorico.findFirst({ orderBy: { anoMes: 'desc' } });

  // 3. Aplica a equivalência matemática canônica
  const valorAtualizado = atualizarParcela(parcela.cotaCUB, cubAtual.valor);

  return res.json({
    parcelaId,
    cotaCUB: parcela.cotaCUB,         // ex: 4.9991 CUBs
    cubAplicado: cubAtual.valor,      // ex: R$ 3.171,96
    valorBoletoReais: valorAtualizado // ex: R$ 15.856,94
  });
}

05. Cuidados no Backend Node.js

Edge Cases & Gotchas Críticos em JavaScript

Armadilhas frequentes de ponto flutuante e regras contratuais.

01. Ponto Flutuante (IEEE 754)

Em JavaScript, 0.1 + 0.2 !== 0.3. Nunca divida e multiplique repetidas vezes em memória sem arredondar. Use Math.round(cota * 10000) / 10000 ou bibliotecas de precisão como decimal.js para grandes volumes.

02. Cláusula de Não-Deflação

Se o CUB divulgado em um mês apresentar deflação (queda), contratos imobiliários padrão proíbem a redução do saldo nominal. Implemente: Math.max(cubAtual, cubBase) no seu service.

03. Competência e Publicação

O Sinduscon divulga o CUB do mês $M$ até o 5º dia útil do mês $M+1$. Para boletos com vencimento no início do mês, o backend Node deve usar o último CUB efetivamente homologado e disponível em cache.
